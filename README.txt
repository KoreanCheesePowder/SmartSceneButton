C.P WheelButton v1.0.0

Tuya TS004F Zigbee 휠 버튼을 위한 SmartThings Edge 드라이버입니다. 버튼 동작과 휠 회전 방향을 자동화 조건으로 사용할 수 있습니다.

지원 동작
- 1회 클릭: pushed
- 2회 클릭: double
- 길게 누름: held
- 오른쪽 회전: right
- 왼쪽 회전: left
- 배터리 상태 조회
- refresh 실행 시 배터리와 Driver Information 갱신

설치
1. 압축을 풉니다.
2. SETUP-AND-INSTALL.cmd를 실행합니다.
3. SmartThings 앱을 완전히 종료한 뒤 다시 실행합니다.
4. 기존 휠 버튼에서 드라이버 변경으로 C.P WheelButton을 선택합니다.
