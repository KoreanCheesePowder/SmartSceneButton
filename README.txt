C.P WheelButton v1.0.5 - 좌우 회전 루틴 횟수 설정

기존 사용자 업데이트:
1) ZIP을 새 폴더에 모두 압축 해제합니다.
2) 기존 드라이버를 설치한 SmartThings 계정으로 UPDATE-ONLY.cmd를 실행합니다.
3) SmartThings 앱에서 휠 버튼 > 우측 상단 ... > 설정을 엽니다.
4) "오른쪽 회전 루틴 실행 횟수"와 "왼쪽 회전 루틴 실행 횟수"를 각각 1~20회로 설정합니다.
   기본 설정은 오른쪽 5회 / 왼쪽 5회입니다.
5) 휠 버튼의 기존 루틴은 유지하고 각 방향의 회전으로 확인합니다.

동작:
- Zigbee Level.Step 또는 기존 OnOff.0xFC의 각 회전 수신 패킷 1개를 1회로 계산합니다.
- 예: 오른쪽 설정 5회라면 같은 방향으로 1~4회는 이벤트/루틴을 발생시키지 않고,
      연속 5회 수신 시 Wheel Action(right) 및 기록용 button(up)을 각각 1번 전송합니다.
- 왼쪽 설정도 별개로 적용합니다. 3회로 설정 시 3회마다 이벤트 1번 전송됩니다.
- 방향이 바뀌거나 마지막 회전 이후 3초 이상 쉬었다가 다음 입력을 받으면 누적 횟수를 초기화합니다.
- 클릭, 더블 클릭, 길게 누르기가 들어와도 회전 누적 횟수를 초기화합니다.
- 5회 충족 후 횟수를 다시 0부터 세므로 10회 연속 회전이면 2회 실행됩니다.
- 횟수는 회전 패킷 수를 뜻하며 실제 물리적 톱니/회전 각도와 다를 수 있습니다.
- 클릭 / 더블 클릭 / 길게 누르기 / 배터리 / 제작자 정보 / 기존 패킷 처리 유지.
- 기존 Wheel Action 및 button up/down Capability ID와 프로필 구성 요소는 유지합니다.
- v1.0.5는 기존 장치에 새 설정을 보이기 위해 호환 프로필로 자동 전환을 요청합니다.
  초기 설정 화면이 보이지 않으면 앱을 완전히 종료했다가 다시 열어 보세요.
  그 뒤에도 보이지 않으면 장치 삭제/재페어링하지 말고 드라이버 로그를 확인하세요.

주의:
- 회전 지정 횟수에 도달하기 전에는 Wheel Action 카드도 이전 완료 상태를 유지합니다.
- 기록에 표시되는 이벤트는 v1.0.4와 같은 버튼 UP/DOWN 표준 이벤트입니다.
- 별도 새로운 Capability 또는 신규 드라이버 채널을 생성하지 않습니다.
- SmartThings 실기기와 앱 UI 및 루틴은 로컬 모의 테스트로 검증할 수 없습니다.
